The Grand Hotel Tycoon

Description

The Grand Hotel Tycoon is an AI-driven simulation mini-game developed in Unity using GOAP (Goal-Oriented Action Planning) technology. Set in a cozy, laid-back small town, the game simulates a fully automated hotel eco-system.

The hotel is populated by autonomous AI agents (Clients, Receptionists, Chefs, and Waiters). Each agent possesses its own set of dynamic goals, preconditions, and actions. They analyze the world state and automatically plan their paths and behaviors to achieve their targets. Watch the hotel come to life fully on autopilot!

Tech Stack

Unity, C#, GOAP (Goal-Oriented Action Planning)

Status

In active development (Future updates planned)

AI System Explanation

The Core Idea: Let AI Agents to achieve goals Independently The agent in this hotel behave like real people. Each agent continuously balances its own needs with the hotel's ever-changing demands, like preparing meals, serving guests, or handling unexpected situations. Here's a glimpse behind the scenes at how every hotel resident thinks, makes decisions, and adapts to the world condition them.

1. Agent: Client (Guest)

The Client agent simulates a complete guest lifecycle, transitioning dynamically from arrival, relaxation, and dining, to checkout.

Core Objectives (Sub-Goals):

  • hasRegisted — Agent should go to reception to get registered and receive his room key (Priority: 5)
  • isSitting / takeAShower — Agent wants to rest on a chair or take a shower to relax himself (Priority: 4)
  • isRested / eatBreakfast / hasPackedLuggage / hasCheckOut / leaveHotel — Agent needs to sleep well, have meal, pack bags, pay the bill and finally leave the hotel (Priority: 3)
  • goToRoom — Agent should move to his assigned room to stay or rest (Priority: 1)

2. Agent: Receptionist

The Receptionist acts as the bridge between incoming guests and room allocation, monitoring the global queue state.

Core Objectives (Sub-Goals):

  • isWorking — Agent should stay at the desk and help guests with check-in procedures (Priority: 3)

Action Planner Layout:

Action / Event Target Area Precondition After Effects / Impact
ReceivingGuestsToCheckIn Reception Desk guestWaitingCheckIn > 0
(Global state triggers this action)		 isWorking = 1
(Global: guestWaitingCheckIn -1)

3. Agent: Chef

The Chef manages the hotel’s food supply, using an observer-like timer pattern to detect when resources are depleted and then shifting goals to restock.

Core Objectives (Sub-Goals):

  • isCooking — Agent needs to prepare meals when food stock is low or empty (Priority: 5) — Triggered dynamically when food runs out
  • prepareFood — Agent should gather ingredients and get ready for cooking (Priority: 3)

Action Planner Layout:

Action / Event Target Area Precondition After Effects / Impact
PrepareFood Kitchen Public Area 1/2/3 - prepareFood = 1
Cook Kitchen B FoodIsEmpty
(Triggered via a 60-second recurring simulation loop)		 IsFoodReady = 1, isCooking = 1

4. Agent: Waiter

The Waiter maintains hospitality standards by roaming public areas and delivering meals once the Chef prepares them.

Core Objectives (Sub-Goals):

  • getFood — Agent must pick up prepared meals from kitchen and bring to guests quickly (Priority: 5) — High priority to serve hungry guests quickly
  • serviceGuest — Agent walks around public areas to check and serve guests' needs (Priority: 3)

Future Implementation

The journey doesn't stop here! The Grand Hotel Tycoon is a living project, and I plan to keep expanding it into a full-fledged simulation game. Here is the roadmap for what I’m building next:

More Diverse AI & Smarter Brains

I want to introduce new agent types (like diligent Housekeepers to clean rooms and handy Repairpersons to fix broken facilities). I will also give existing agents more sub-goals to make their daily routines feel even more realistic and unpredictable.

A Complete Game Loop (UI & Menus)

To turn this technical simulation into a real game, I will design and implement a polished Main Menu, an intuitive Settings Panel, and a rich In-Game UI so players can track hotel stats, revenue, and agent moods in real-time.

Autonomous AI Conversations

Imagine two agents bumping into each other in the corridor and actually having a chat! I plan to implement a dynamic conversation system where agents can "talk" to each other based on their current states (e.g., a hungry guest complaining to a waiter, or the receptionist greeting the chef).

Tycoon Economy System

I will add financial mechanics where clients pay for their rooms, food, and services, allowing the player to reinvest that money to expand the hotel, buy better furniture, and unlock new AI behaviors.
